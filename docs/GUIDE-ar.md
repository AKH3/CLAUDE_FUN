# دليل التشغيل للمبتدئين · لوحة كلاود

هذا الدليل يأخذك خطوة بخطوة من جهاز لا يوجد عليه شيء إلى أول مشروع يعمل فيه كلاود وأنت تتابعه من اللوحة. الأوامر مكتوبة لـ Windows، وكل أمر في مربع مستقل: انسخه والصقه كما هو ثم اضغط Enter.

[العودة إلى الصفحة الرئيسية](../README.md)

---

## الفكرة في سطرين

بدل أن يكتب لك كلاود فقرات طويلة في الطرفية عن الخطة وما أنجزه، يرسل تحديثات قصيرة جداً، فتظهر أمامك في المتصفح لوحة فيها مراحل المشروع وخطواته. لا يبدأ كلاود أي خطوة حتى تضغط أنت «اعتماد البدء».

---

## الخطوة 1: افتح الطرفية

اضغط زر Windows، واكتب `PowerShell`، ثم افتحه. هذه النافذة السوداء أو الزرقاء هي «الطرفية» التي سنكتب فيها كل الأوامر.

> **مهم على Windows:** اكتب دائماً `npm.cmd` بدل `npm`، و `claude-fun.cmd` بدل `claude-fun`. بدون `.cmd` قد يظهر لك خطأ أحمر فيه `UnauthorizedAccess`، وسببه إعداد أمان في PowerShell وليس خللاً في الأداة.

---

## الخطوة 2: تأكد من وجود المتطلبات

تحتاج ثلاثة برامج. شغّل كل أمر وانظر إلى النتيجة:

```powershell
node -v
```

يجب أن يظهر رقم يبدأ بـ `v22` أو أعلى. إذا ظهر خطأ أو رقم أقل، نزّل Node.js من nodejs.org (نسخة LTS).

```powershell
git --version
```

يجب أن يظهر شيء مثل `git version 2.x`. إذا لم يظهر، نزّل Git من git-scm.com. الأداة تحتاجه لتعرض لك ما عدّله كلاود في كل خطوة.

```powershell
claude --version
```

يجب أن يظهر رقم نسخة Claude Code. إذا لم يظهر، ثبّت Claude Code أولاً من موقع Anthropic.

---

## الخطوة 3: ثبّت الأداة

مرة واحدة فقط على الجهاز:

```powershell
npm.cmd i -g https://github.com/AKH3/CLAUDE_FUN/archive/refs/heads/main.tar.gz
```

انتظر حتى ينتهي، ثم تأكد أن التثبيت نجح:

```powershell
claude-fun.cmd --version
```

إذا ظهر رقم مثل `0.1.0` فكل شيء تمام.

> لتحديث الأداة لاحقاً إلى آخر نسخة، أعد تشغيل أمر التثبيت نفسه.

---

## الخطوة 4: جرّب اللوحة بدون مشروع (اختياري لكن مفيد)

قبل أن تربطها بمشروع حقيقي، شاهدها وهي تعمل:

```powershell
claude-fun.cmd demo --simulate
```

سيفتح المتصفح على لوحة تجريبية. اضغط ✓ «اعتماد البدء» على أي بطاقة تنبض، وسترى «كلاوداً وهمياً» ينفذها: تتحول البطاقة إلى «قيد التنفيذ» ثم «منجزة» وتضيء.

للإيقاف: ارجع إلى الطرفية واضغط `Ctrl + C`.

---

## الخطوة 5: جهّز مجلد مشروعك

### أ) أنشئ مجلداً للمشروع وادخل إليه

مثال لمشروع تجريبي جديد:

```powershell
mkdir "C:\Users\Abdulkarem\Documents\A.1 Programs\board-test"
```

```powershell
cd "C:\Users\Abdulkarem\Documents\A.1 Programs\board-test"
```

> إذا كان المسار فيه مسافات فضعه بين علامتي تنصيص `" "` كما في المثال.

إذا كان عندك مشروع موجود، استخدم `cd` مع مساره هو بدل ما سبق.

### ب) (يُنصح به) فعّل git في المجلد إن لم يكن مفعّلاً

```powershell
git init
```

### ج) اربط المشروع باللوحة

```powershell
claude-fun.cmd init
```

سيطبع لك قائمة بما أضافه، وينتهي بسطر `next: run claude here`.

> ⚠️ **لا تشغّل `init` أبداً في مجلد المستخدم** (`C:\Users\Abdulkarem`) **ولا في جذر القرص** (`C:\`). الأداة ترفض ذلك تلقائياً، لأن الإعدادات هناك تؤثر على كل مشاريعك. تأكد قبل `init` أنك داخل مجلد المشروع.

**ما الذي أضافه `init`؟** لا يمس كود مشروعك. يضيف فقط:

| الملف | ما هو |
|---|---|
| `.claude-board/` | مجلد اللوحة: الخطة وحالة كل خطوة |
| `.mcp.json` | يعرّف Claude Code على اللوحة |
| `.claude/settings.json` | إعدادات تجعل كلاود يتصل باللوحة ويحترم الاعتمادات |
| `CLAUDE.md` | خمسة أسطر تذكّر كلاود بطريقة العمل |

---

## الخطوة 6: شغّل Claude Code

في المجلد نفسه:

```powershell
claude
```

**أول مرة فقط:** سيسألك Claude Code إن كنت تثق بالمجلد، وإن كنت توافق على خادم MCP اسمه `board` موجود في `.mcp.json`. وافق على الاثنين.

للتأكد أن اللوحة متصلة، اكتب داخل Claude Code:

```
/mcp
```

يجب أن ترى `board` وبجانبه أنه متصل (connected).

---

## الخطوة 7: افتح اللوحة

افتح المتصفح على:

```
http://localhost:3000
```

أو افتح طرفية ثانية في مجلد المشروع واكتب `claude-fun.cmd`. كلاود أيضاً يعطيك الرابط في أول رد له.

> إذا كان المنفذ 3000 مشغولاً ببرنامج آخر، تستخدم اللوحة 3001 أو التالي تلقائياً، وكلاود يعطيك الرابط الصحيح.

في البداية ستكون اللوحة فارغة ومكتوب فيها «اللوحة فارغة». هذا طبيعي.

---

## الخطوة 8: أول مهمة

اكتب لكلاود في الطرفية طلباً عادياً، مثلاً:

```
خطط لبناء صفحة ويب بسيطة لقائمة مهام
```

ما سيحدث:

1. يرسل كلاود خطة، فتظهر في اللوحة **مراحل** (أعمدة) وتحت كل مرحلة **خطوات** (بطاقات).
2. كل بطاقة تكون «بانتظار الاعتماد» وتنبض. كلاود الآن ينتظرك.
3. اضغط ✓ **«اعتماد البدء»** على الخطوة التي تريده أن يبدأ بها، أو **«اعتماد المرحلة»** لاعتماد مرحلة كاملة.
4. يكمل كلاود وحده: تتحول البطاقة إلى «قيد التنفيذ» ثم «منجزة» أو «فشلت».
5. تحت كل خطوة منجزة ترى النتائج: عدد الملفات، والأسطر المضافة والمحذوفة، والاختبارات، والمدة، والتوكنز.

## ما تستطيع فعله من اللوحة

| تريد أن… | افعل هذا |
|---|---|
| تسمح لكلاود ببدء خطوة | ✓ «اعتماد البدء» |
| تسمح بكل خطوات المرحلة | «اعتماد المرحلة» |
| تبدأ عدة مهام بترتيب تختاره | اضغط `#` على كل بطاقة بالترتيب (تظهر 1، 2، 3)، ثم «ابدأ بالترتيب» في الشريط السفلي |
| تعرف ما هي الخطوة وما فائدتها | اضغط `?` على البطاقة، ويظهر شرح كلاود المختصر في اللوحة الجانبية |
| تطوي خطوات مرحلة أو تعرضها | اضغط على بطاقة المرحلة نفسها |
| ترى تفاصيل مرحلة | زر ⓘ على بطاقة المرحلة |
| تقسّم خطوة كبيرة إلى أصغر | ✂ «قسّم الخطوة» |
| تلغي خطوة لا تريدها | «رفض» |
| تعيد خطوة فشلت | «إعادة» |
| ترى بالضبط ما عدّله كلاود | «عرض التعديلات» |
| تغيّر ترتيب الأولوية | اسحب البطاقة للأعلى أو للأسفل |
| تعطي كلاود ملاحظة على خطوة | اكتبها في خانة الملاحظة على البطاقة، وتصله مع خطوته القادمة |
| تضيف خطوة أو مرحلة بنفسك | «أضف خطوة» أو «مرحلة جديدة» |
| تغيّر اللغة أو الثيم | زر `EN` / «داكن» و«فاتح» أعلى الصفحة |

### الأعمدة الصغيرة بجانب رقم الخطوة

هي **الجهد المتوقع** الذي قدّره كلاود: عمود أخضر = خفيف، عمودان برتقاليان = متوسط، ثلاثة أعمدة = كبير.

### حارس التعديلات (أعلى اللوحة)

| الوضع | معناه | متى تستخدمه |
|---|---|---|
| **صارم** | كلاود لا يعدّل أي ملف إلا أثناء خطوة اعتمدتها | الافتراضي، وهو الأنسب للمبتدئ |
| **الحساس** | يحمي فقط الملفات الحساسة مثل `.env` | إذا أردت حرية أكثر لكلاود |
| **مطفأ** | بدون حماية | لا يُنصح به |

## الخطوة 9: العودة في يوم آخر

لا تحتاج أن تشرح لكلاود ما حدث سابقاً. افتح الطرفية، وادخل مجلد المشروع، وشغّل `claude`:

```powershell
cd "C:\Users\Abdulkarem\Documents\A.1 Programs\board-test"
```

```powershell
claude
```

كلاود يقرأ ملخصاً قصيراً من اللوحة ويكمل من حيث توقفتما. ولترى الملخص بنفسك بدون فتح كلاود:

```powershell
claude-fun.cmd status
```

## تحديث الأداة إلى آخر نسخة

1. أغلق جلسات Claude Code المفتوحة على مشاريع فيها اللوحة، لأنها تبقى على النسخة القديمة حتى تُعاد.
2. شغّل أمر التثبيت مرة ثانية. الإضافة `--prefer-online` تجبر npm على تنزيل النسخة الجديدة بدل نسخة قديمة محفوظة عنده:

```powershell
npm.cmd i -g --prefer-online https://github.com/AKH3/CLAUDE_FUN/archive/refs/heads/main.tar.gz
```

3. تأكد من رقم النسخة:

```powershell
claude-fun.cmd --version
```

4. (اختياري لكن يُنصح به) ادخل كل مشروع وشغّل `init` مرة ثانية. لا يمسح خطتك، فقط يحدّث الإعدادات:

```powershell
claude-fun.cmd init
```

5. افتح Claude Code من جديد في المشروع.

> أسهل طريقة: إذا كانت مهارة `claude-board-setup` مثبتة عندك، قل لكلاود «حدّث لوحة كلاود» وهو ينفّذ هذه الخطوات.

---

## إزالة الأداة من مشروع

داخل مجلد المشروع:

```powershell
claude-fun.cmd remove
```

يلغي ما أضافه `init` ويحتفظ بنسخة احتياطية، ويطبع لك مكانها. اللوحة نفسها (الخطة وتاريخها) تبقى. لحذفها أيضاً أضف `--purge`:

```powershell
claude-fun.cmd remove --purge
```

## مشاكل شائعة وحلولها

| المشكلة | الحل |
|---|---|
| خطأ أحمر فيه `UnauthorizedAccess` أو `PSSecurityException` | اكتب `npm.cmd` و `claude-fun.cmd` بدل `npm` و `claude-fun` |
| `'claude-fun.cmd' is not recognized` | التثبيت لم يكتمل. أعد الخطوة 3، ثم أغلق PowerShell وافتحه من جديد |
| `... is not a project folder` | أنت في مجلد المستخدم أو جذر القرص. ادخل مجلد المشروع بـ `cd` ثم أعد الأمر |
| `/mcp` لا يُظهر `board` | تأكد أنك شغّلت `claude` داخل المجلد الذي شغّلت فيه `init`، ثم أغلق كلاود وأعد فتحه |
| اللوحة لا تفتح على 3000 | المنفذ مشغول. استخدم الرابط الذي يعطيك إياه كلاود، أو اكتب `claude-fun.cmd status` |
| كلاود توقف عن الانتظار قبل أن تعتمد | طبيعي بعد عدة دقائق. اكتب له «كمل» بعد أن تعتمد من اللوحة |
| نقلت مجلد Node أو أعدت تثبيت الأداة | شغّل `claude-fun.cmd init` مرة ثانية داخل المشروع |

## قاموس سريع

| الكلمة | معناها |
|---|---|
| **الطرفية (Terminal)** | النافذة التي تكتب فيها الأوامر، مثل PowerShell |
| **Claude Code** | كلاود الذي يعمل داخل الطرفية ويعدّل ملفات مشروعك |
| **MCP** | الطريقة التي يتصل بها كلاود بأدوات خارجية، ومنها هذه اللوحة |
| **Hook** | أمر صغير يشغّله Claude Code تلقائياً في لحظات معينة، مثل منع التعديل قبل الاعتماد |
| **التوكنز (Tokens)** | وحدة قياس استهلاك كلاود. كلما قلّت، قلّت التكلفة |
| **localhost** | جهازك أنت. اللوحة لا تخرج إلى الإنترنت |
| **Diff** | الفرق بين الملف قبل التعديل وبعده |
